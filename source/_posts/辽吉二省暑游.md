这趟旅行结束以后，我最先想留下来的并不是一份“几天几夜攻略”，而是一条路线。

**旅顺 → 大连 → 长春 → 吉林 → 延吉 → 珲春 → 沈阳。**

从海边一路向北，再从边城折回辽宁。城市一个接一个地换，窗外的风景也不断变化。等真正回过头看，才发现旅行的记忆从来不是按地图整齐排列的，而是由一些很具体的小片段组成：一个车站、一顿饭、一条街、突然下起的雨，或者某个原本没有安排却意外喜欢上的地方。

<!-- more -->

> 这篇目前先作为旅程的“序章”。接下来会根据照片、路线和每天的细节继续补全，不急着一次写完。

## 路线总览

### 01 · 旅顺

这趟东北之行从旅顺开始。

这里想补下来的，不只是景点，而是第一次真正进入这段旅程时的感觉：天气、海风、公交车窗外的街道，以及当天最意外的一件小事。

**待补充：** 到达方式 / 走过的路线 / 最喜欢的一处 / 当天照片。

### 02 · 大连

从旅顺回到大连，城市的节奏一下子变得更鲜明。

关于大连，我更想记录“海边城市的日常感”，而不是把所有地标排成清单。哪些地方真的值得停下来，哪些时刻比计划里的景点更有意思，等整理照片时再慢慢补上。

**待补充：** 海边 / 街区 / 吃过的东西 / 夜晚。

### 03 · 长春

从辽宁进入吉林以后，旅行的气质开始变化。

长春会是这篇游记里一个很适合写“城市印象”的章节：第一眼是什么颜色、街道给人的尺度感、一天结束后脑子里最先浮出来的画面是什么。

**待补充：** 交通 / 城市散步 / 一处最值得回想的地方。

### 04 · 吉林

吉林这一站，我想把重点留给“水”和城市之间的关系。

不急着写成攻略，更想保留当时真正走在城市里的感觉。

**待补充：** 松花江边 / 路线 / 天气 / 随手拍。

### 05 · 延吉

延吉大概会是整趟旅程里风格最鲜明的一站之一。

语言、招牌、食物和街道让城市拥有非常直接的辨识度。比起“打卡”，我更想写那些只有真的走进去以后才会注意到的细节。

**待补充：** 街道 / 市场或餐馆 / 夜景 / 最喜欢的一顿饭。

### 06 · 珲春

走到珲春时，已经离最开始的海边很远了。

“边城”这个词在地图上很抽象，但真正来到这里以后，它会变成具体的距离感、道路和城市气氛。

**待补充：** 当天往返方式 / 海鲜或市场 / 边城印象 / 一张代表照片。

### 07 · 沈阳

最后回到辽宁，在沈阳收尾。

旅行到最后几天，人通常已经不像刚出发时那样兴奋，反而会开始自动整理这一路发生过的事情。对我来说，沈阳不仅是一个新的城市，也是这趟路线的句号。

**待补充：** 沈阳故宫之后的行程 / 博物馆或街区 / 最后一晚。

## 这篇游记最终想留下什么

我不太想把它写成一篇信息密度很高、过几年就会过时的攻略。

更希望最后整理出来的是一份可以在很久以后重新打开的“旅行档案”：

- 每座城市真正走过的路线；
- 几张最有代表性的照片；
- 当时觉得很好吃的一顿饭；
- 一件没有计划却记得很久的小事；
- 以及旅行结束后，自己对这片地方留下的整体印象。

等细节补全以后，这条从旅顺出发、经过吉林一路走到边城、最后回到沈阳的线，应该就不再只是地图上的几个地名了。
